# Water Monitoring System ◈ Sabana Centro

**Resiliencia hídrica para una región bajo presión climática.** Telemetría distribuida, fusión sensorial e inteligencia artificial al servicio del agua dulce en la Sabana Centro de Cundinamarca.

---

## ⬡ ¿Qué es WMS y por qué es innovador?

WMS es una plataforma de monitoreo hidrometeorológico de bajo costo diseñada para cerrar la brecha de observación en reservorios y fuentes de agua dulce de la Sabana Centro. Ante la intensificación del Fenómeno de El Niño, la región carece de instrumentación densa y asequible que permita anticipar el estrés hídrico. WMS responde con una red de nodos embebidos capaces de adquirir, fusionar y transmitir variables críticas en tiempo casi real.

El sistema combina una **arquitectura dual borde/nube**: el nodo ESP32 ejecuta adquisición no bloqueante bajo FreeRTOS e ISRs, sirve un tablero local por WLAN y aplica lógica de fusión sensorial antes de publicar por MQTT. Un gateway Raspberry Pi concentra la telemetría en un broker Mosquitto con persistencia en SQLite, garantizando operación continua incluso ante cortes de conectividad hacia la nube.

Sobre esa base, WMS integra **inteligencia artificial descentralizada** vía API para análisis predictivo y soporte de racionamiento, transformando datos crudos en decisiones accionables. El resultado es un instrumento replicable, auditable y orientado a la gestión preventiva del recurso hídrico.

## ⚡ System Snapshot

<Info>
  Ficha técnica resumida del prototipo funcional. Las especificaciones reflejan la configuración de referencia para la Sabana Centro.
</Info>

| Parámetro | Especificación |
| --- | --- |
| **Variables monitoreadas** | Nivel, caudal, radiación solar, temperatura, humedad relativa, presión atmosférica |
| **Nodo embebido** | ESP32 · FreeRTOS · ISRs · servidor web local |
| **Gateway local** | Raspberry Pi 4 · broker MQTT Mosquitto · base de datos SQLite |
| **Protocolos** | MQTT bidireccional · HTTP (tablero local) · WLAN |
| **Latencia estimada** | ▸ Borde a gateway: \< 2 s · Gateway a nube: \< 10 s |
| **Redundancia** | Persistencia local SQLite + reenvío en reconexión |
| **Actuadores** | Alarma sonora/lumínica con apagado remoto (ACK) · pantalla in situ |
| **Inteligencia** | API de IA para análisis predictivo y soporte de racionamiento |
