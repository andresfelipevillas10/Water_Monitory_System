**El Fenómeno de El Niño 2026 amenaza el suministro hídrico de la Sabana Centro.** WMS responde con telemetría distribuida, fusión sensorial e inteligencia artificial para anticipar el estrés hídrico antes de que sea irreversible.

---

## ⬡ ¿Qué es WMS?

El [Fenómeno de El Niño 2026](https://www.ideam.gov.co) ha intensificado la presión sobre las fuentes hídricas de la **Sabana Centro de Cundinamarca**, una región de más de 400 000 habitantes cuyo suministro depende de reservorios superficiales con escasa instrumentación. El [IDEAM](https://www.ideam.gov.co) y la [CAR Cundinamarca](https://www.car.gov.co) identifican esta brecha de observación como el principal obstáculo para la gestión preventiva del recurso.

**WMS cierra esa brecha** con una red de nodos embebidos de bajo costo capaces de adquirir, fusionar y transmitir variables hidrometeorológicas críticas en tiempo casi real, sin depender de infraestructura costosa ni conectividad permanente.

El sistema combina una **arquitectura dual borde/nube**: el nodo ESP32 ejecuta adquisición no bloqueante bajo [FreeRTOS](https://www.freertos.org) con ISRs, sirve un tablero local por WLAN y aplica fusión sensorial antes de publicar por MQTT. El gateway Raspberry Pi concentra la telemetría en un broker [Mosquitto](https://mosquitto.org), con persistencia en SQLite para garantizar operación continua ante cortes de conectividad.

Sobre esa base, WMS implementa una **arquitectura híbrida de inferencia en la nube**: el gateway orquesta consultas a la [API de Gemini](https://ai.google.dev) para análisis predictivo y soporte de racionamiento, transformando datos crudos del terreno en recomendaciones accionables. El modelo de lenguaje corre en servidores de Google; la lógica de orquestación, los prompts y la persistencia de resultados residen en el gateway local.

<Card title="🔬 Sensores e Interfaces Físicas" icon="microchip" href="/modulos/04-hardware">
  | Variable | Sensor | Bus / Interfaz |
  | --- | --- | --- |
  | Nivel de agua | HC-SR04 (ultrasónico) | GPIO — trigger/echo |
  | Caudal | YF-S201 (caudalímetro) | Interrupción externa (pulsos) |
  | Temperatura / Humedad | DHT22 | OneWire / Single-bus |
  | Radiación solar | LDR (fotorresistencia) | ADC 12 bits (GPIO34) |
  | Presión atmosférica | BMP280 | I²C (SDA/SCL) |
  | Evaporación potencial | Calculada en gateway | Método Hargreaves (T + Rad) |
</Card>

<Card title="🖥️ Cómputo y Conectividad" icon="server" href="/modulos/03-solucion-y-arquitectura">
  | Componente | Detalle |
  | --- | --- |
  | Nodo embebido | ESP32 · FreeRTOS · ISRs · servidor HTTP local |
  | Gateway local | Raspberry Pi 4 · Mosquitto broker · SQLite |
  | Protocolo campo → gateway | MQTT bidireccional (TCP/IP · WLAN) |
  | Protocolo gateway → nube | MQTT → [Ubidots](https://ubidots.com) (token auth) |
  | Latencia borde → gateway | \< 2 s |
  | Latencia gateway → nube | \< 10 s |
  | Redundancia | SQLite local + reenvío automático en reconexión |
</Card>

<Card title="🔒 Seguridad y Control de Acceso" icon="lock" href="/modulos/05-software-y-red">
  | Capa | Mecanismo |
  | --- | --- |
  | Tablero local (ESP32) | HTTP Basic Auth sobre servidor embebido |
  | Gateway (Mosquitto) | Usuario + contraseña · ACL por tópico |
  | Tablero global (Ubidots) | API Token + RBAC por dashboard |
  | Actuadores remotos | Comando ACK autenticado vía tópico MQTT restringido |
</Card>

<Card title="🧠 Inteligencia y Actuación" icon="brain-circuit" href="/modulos/06-modulo-ia">
  | Función | Implementación |
  | --- | --- |
  | Modelo de IA | [Gemini API](https://ai.google.dev) — inferencia en nube |
  | Orquestación | Gateway RPi · Python · prompts auditables |
  | Análisis | Detección de anomalías · soporte de racionamiento |
  | Actuadores | Alarma sonora/lumínica · pantalla in situ · ACK remoto |
</Card>
