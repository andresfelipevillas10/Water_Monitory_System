# Equipo y Roles ⬡ Sinergia e Ingeniería Distribuida

**Tres ingenieros, cuatro capas.** La arquitectura del Challenge #3 reparte el borde, el gateway, la nube y la IA en responsabilidades claras y complementarias, de modo que cada nivel del sistema tenga un dueño técnico y un soporte definido.
