## ⚡ Glosario Técnico

| Término | Definición |
| --- | --- |
| **Edge Computing** | Procesamiento de datos en el nodo de borde, cerca de la fuente, en lugar de en la nube. |
| **ISR** | Rutina de servicio de interrupción; ejecuta código ante un evento de hardware sin bloquear el flujo principal. |
| **Broker MQTT** | Servidor intermediario que enruta mensajes entre publicadores y suscriptores (Mosquitto). |
| **QoS** | Calidad de servicio: nivel de garantía de entrega de un mensaje MQTT. |
| **WLAN Hotspot** | Red local inalámbrica que sirve el tablero in situ del ESP32. |
| **Persistencia SQLite** | Almacenamiento local de la telemetría en el gateway para tolerancia a fallos. |
| **ACK (Acknowledge)** | Confirmación de recepción; aquí, orden de silenciado remoto de la alarma. |
| **Offline First** | Filosofía de diseño que garantiza operación continua aun sin conectividad a Internet. |
| **Índice de Riesgo (Fusión)** | Métrica ponderada 80/20 que combina nivel físico y variables ambientales. |
